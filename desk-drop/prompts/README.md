# Agent prompts

Eight self-contained prompts, one per digital workstream, each meant for a separate agent. Every prompt repeats the same context block on purpose, so each one can be pasted alone.

How to use them
- 

Attach the plan file (plan.md, the export of this document's main tab) to every prompt. Each prompt tells the agent to read it first.
- 

Copy a prompt from its title line to the end of its Report back section.
- 

Leave the placeholders ([FOUNDER NAME], [PHONE], [EMAIL], [POSTAL ADDRESS]) in place. The agents keep them as placeholders until you fill them.
- 

All eight can start today. Dependencies are soft: each prompt says what to do when an input from another workstream is not ready.
- 

If you run them in waves: wave one is B (cluster map), D (identity), G (legal), H (financial model). Wave two is A (Clay), C (website), E (outreach), F (operations), which consume something from wave one but can begin with provisional inputs.
- 

Before sending A, know whether you have a Clay account and which Google account to share with. Before sending C, know your domain. Before sending E, decide which postal address goes in the email footer (a mailbox service is fine).
