# Tests

Run everything with `bash tests/run-all.sh` from the `desk-drop-identity` folder (Node 18+, Playwright, ImageMagick, poppler's pdftotext, pdfinfo and pdftoppm). The visual tests write images for a person to look at; I looked at every one listed here. Results below are from 2026-10-24: **28 of 28 suite steps pass** (with `DD_QR_DECODER` set; 27 plus one skip without it), and the documents step runs 53 checks.

## Files

- `run-all.sh`: the whole suite. `check-tokens.js`: token and contrast check.
- `photo-sim/`: wide and close photo simulation, allergen size sweep, outputs in `photo-sim/out/`.
- `downscale/`: 120 px and 60 px contact sheets.
- `name-length/`: rename test and its images.
- `guide-walkthrough/`: the stranger test (`walkthrough.js`), the swap test (`swap-test.js`, `swap-*.png`, `swap-result.json`) and their screenshots.
- `documents/`: `doc-tests.js` (53 checks on the documents, signature and avatar) and `limitations-frozen.txt`.
- `rename-documents/`: the documents rendered with the name "Dropp".
- `signature/`: a filled SAMPLE `brand.json` and the signature built from it.
- `avatar/`: the 40 px avatar enlarged to inspect pixels.
- `out/`: renders used by the tests (SAMPLE data only).

## Limits of these tests

The swap-test time is a model, not a stopwatch on a person. The first real person to make a card should time it and write the minutes into this file.


The photos are simulations, not photographs of a printed card on a real shelf. Before the first drop, print one card on the real stock, stand it in a real pantry with real product, take both photos with the phone you will use, and check the same three things (name from across the room, allergen panel when zoomed, QR scans). The plan already asks for this test on a real shelf the week before campaign zero.
