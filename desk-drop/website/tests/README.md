# Tests

Run everything from `website/`: `bash tests/run_all.sh` (about 10 minutes; `--no-lighthouse` skips the slow part). To keep a log: `bash tests/run_all.sh 2>&1 | tee tests/out/run_all.log`. The last step prints the publish preflight, which blocks by design until the founder's steps are done.
Needs python3, node 22, Playwright with Chromium (installed globally here), and once: `cd tests && npm install` (axe-core 4.14.0, Lighthouse 13.5.0, html-validate 11.16.2, all pinned). Outputs go to `tests/out/`; screenshots to `_shots/`.
